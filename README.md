# 寻长生 · 青岚山境

## 第一卷试玩版

在 macOS 双击 `Builds/QinglanDemo.app`。使用 Unity 6000.6.0f1 时，打开 `Assets/Qingxi/Scenes/QingxiTrail.unity` 并点 **Play**，进入同一个卷首。

**剧情**从十六岁的药铺学徒沈砚起步。**沙盒**可自取姓名、选天灵根或杂灵根，以药铺寄学或已初感灵气的游方散修开局。两个模式各有一个本机自动存档。首次打开剧情页可以选择接续旧版学徒手记。**F2 → 保存并返回卷首** 可切换角色，重新开卷会先确认。恢复未完的筑基时会回到原来那一转。

### 从青溪到筑基

1. **在镇里谋生。** 学徒从药谱、活株和一趟卖药生意获得借读《听息诀》的机会。药铺东侧静席可自修，也可先找东门外的散修指点。游方散修可以直接出镇。
2. **自己去找功法。** 走到青溪东门牌坊，按 **M** 展开舆图。官道可循路赶往栖霞宗，山径要亲自走通才会记入舆图。到达山门按 **E** 进庭院，拜访执事或打开 **F1 修行簿** 借《归元篇》。愿意入外门的角色可以挂籍当值，散修也能习得此卷。
3. **安排岁月和资源。** 在镇中或宗门自定闭关时长，普通闭关的已修成果会保留。炼气中期可御剑，耗时随距离改变，飞越山脊要有足够法力。可在丹房做工、到松风隘采芝、与姜遥约定交药或自行炼丹。闭关、采集和行旅都会推进她的行程。
4. **按自己的时机冲关。** 炼气圆满后，在静处决定用几枚筑基丹、是否服护脉露。七转之内从五行气池中取同气凝基，达到门槛后剩余轮次可继续打磨根基。失败或强行出关会耗去已用的药、回退修为并添一层旧伤。护脉露暂压一回旧伤，再败会接着原层数累加。成功后有本卷结语，可以继续游历。

**斗法为可选路线。** 青溪镇、镇外山林、栖霞山门和松风隘可按 **T** 在脚下试阵。初感灵气后，在青溪山脚找到巡山弟子，按 **G** 接松林护药。独行只带自己的傀儡，同行的采药客可以自行作战，立临时指挥契才可操控他。重伤倒地有两回合救援机会，可放弃兽蜕将人带走。走采药、交托和炉工路线也能筹足筑基所需。

**松风隘东岔的灰衣客**可以绕过。要与他交涉，可先看看同伙有没有让开归路，再按 **G** 搭话。他开的价、你的判断、舍不舍得动用破阵符，都会影响这次遭遇。主动选择并确认死斗后，负伤倒下可能结束这个角色的一生。在战中可以弃财撤离；死斗中途关闭游戏，续档依开战前告知的弃财绕行规则结算。

**常用操作**　WASD / 方向键行走，**E** 就近互动，**J** 打开草木手记，**F1** 看修行与准备，**F2** 看当前去向和卷册。区域舆图中 **Tab** 查行程、**F** 御剑、**R** 在可落脚处调息。点击界面按钮也能进行交谈、战棋行动和冲关。

开发验证可在 Unity 菜单选择 **行旅 → 验证第一卷**。选择 **行旅 → 构建第一卷 macOS 试玩版** 会重新生成包含青溪与区域两张场景的播放器。

## 青溪镇原生 2D 场景

在剧情档里从镇中药铺出发，用 **WASD 或方向键** 沿街走出镇，观察山脚的地形，试着自己找到进山的小径。镇内外连续可走。走到小径入口会记下一笔，按 **R** 可回到镇里重新试走，角色档会保留这次发现。

场景内的房屋、镇门、树石、道路和地标触发区都可以在 Hierarchy 选取，在 Scene 视图移动。角色使用 Rigidbody2D 和 Collider2D 沿地面行走，正交相机跟随。占位精灵在 `Assets/Qingxi/Art`。

## 药铺学徒 · 草木手记

仍在同一张青溪镇地图里点 **Play**。从药铺柜台前按 **E** 翻《山行药谱》，读货单和夹页，按 **1 / 2 / 3** 或点击条目，把自己的生境猜测写入手记。**J** 随时翻看手记，**Esc** 合上。原先记错的猜测可以回铺改写，也可以留到亲验时对照。

出镇后自己辨路寻草。找到活株时靠近按 **E**，用白布查叶纹、用竹签查根土。两项观察各自留下证据，对照药谱亲自确认后才会记为掌握。先在山中遇到活株，也可以先记观察、回铺定名。手记随角色保存在本机，重新进入 Play 并续档或按 **R** 回镇都会保留已写的记录。

东门外的采药散修知道一段山路。靠近按 **E** 攀谈，可以把手记里的一条猜测告诉他来换路讯，也可以保留猜测，约定卖药后与他平分药钱。按 **3** 可以告辞，自己探路。**J** 打开手记后按 **Tab** 可翻到往来账，回看他的原话和自己答应的条件。

掌握青纹草后，靠近活株按 **E**，再按 **3** 留根采一份鲜药。带回青溪药铺，在柜台按 **E** 再按 **Enter** 交货。掌柜出价六文，约好平分则实收三文。这一趟只结一次账，药囊和收据会随手记保存。上一版已经掌握青纹草的角色可以直接从采药接着玩。

### 听息入门

交过鲜药后，药铺东侧的蒲团上可借阅《听息诀》。靠近按 **E**，选 **1** 坐一时辰，或选 **2** 坐三时辰。自修每时辰积一格感气，六格时第一次辨出灵气，境界仍是凡人。也可以先去东门外找背篓散修按 **1** 花两文请教，此后每时辰积两格。以前交过药的存档可以直接入静。

入静前按 **3** 决定是否听掌柜来唤。修习时按 **Esc** 随时收功，已经坐满的时辰和所得保留。若有人敲门，修习会停下来等你决定。选择出关后要亲自到柜上留样，耗一时辰、得一文；再坐满一时辰，鲜叶便干，机会结束。修习、帮工耗时和钱囊收入都可在 **J → Tab** 的往来账查看。

## 青溪镇 · 就地战棋

在镇中或野外按 **T**，即可在脚下试阵。走到山脚官道上的巡山弟子身旁，按 **E** 或点击邀约，可与他切磋。两种方式均由你操控学徒和练习傀儡，对阵两名预设弟子。此次交手点到为止，结算后会回到起手处继续探索。

全图使用同一套菱形地格。开战时，以当前地形的实体碰撞检测可站位置和格间通路，只有与角色相通的附近地面才会显示。药铺、树石和溪岸会改变可走范围，实心房屋和树石也会遮挡施术。两支队伍使用相同的通行规则。在 Scene 视图选中 **战棋地格** 可查看全图格线并核对关卡摆放。

| 战斗操作 | 操作方式 |
| --- | --- |
| 选学徒或傀儡 | 点己方棋子，或按 Tab 切换 |
| 移动与施术 | 点青色可走格移动，或点射程内的对手施术。键盘可用方向键或 WASD 选格，再按空格 |
| 交给对手行动 | Enter 或点击结束回合。每名己方棋子每回合可移动一次、施术一次 |
| 认输 / 返回探索 | Esc 打开认输，Enter 确认或 Esc 取消；结算后按 E 返回 |

验证战棋通行和回合规则可用 Unity 菜单 **行旅 → 验证切磋规则**。

## 前一版 · 区域行旅测试

Unity 6（6000.6.0f1）的第一阶段可玩地图原型。你从青溪镇南门出发，可以沿河绕行官道，也可以循山径穿过松风隘，到达栖霞宗。镇、隘口、宗门均有可自由走动的局部地图。

### 开始试玩

在 macOS 上打开本地构建 `Builds/QinglanTravel.app`。也可以用 Unity 打开仓库，打开 `Assets/Scenes/SampleScene.unity`，点击 **Play**，再点一下 Game 视图以接收键盘输入。

| 操作 | 按键 |
| --- | --- |
| 自由移动 | WASD 或方向键 |
| 在地点或局部门口进出地图 | E |
| 在大地图御剑或收剑 | F |
| 在可落脚处调息，花两个游戏小时回满法力 | R |
| 在大地图的镇口或山门沿官道、已探明的山路赶路 | 1、2 |
| 中断循路赶路 | 方向键或 Esc |
| 打开或合上行旅簿 | Tab |

### 试走三程

1. **官道步行上山。** 在出生处按 E 出镇，按 1 循官道前往栖霞宗。抵达后按 E 进山门，四处走走，再回南侧出口。
2. **原路御剑回镇。** 回到大地图后按 F 御剑，再按 1 返回。按 Tab 对照两程。钟表按实际走过的距离推进，绕行、途中调息和停留在隘口走动都会影响行程；站着看地图不会耗时。
3. **徒步探山。** 从镇口朝东北找山径，在松风隘可按 E 进入局部地图。走通的路段会逐段标在舆图上，八段全部确认后，镇口和山门都可按 2 循山路往返。御剑飞过山脊只算赶路，勘路需要步行。若直接御剑翻岭，入岭前会核对飞到落脚点所需的法力。

每次启动从镇口开始。已经走通的整段山路和最近八次完整行程保存在本机。调校用的速度、地形耗时、法力消耗和地图坐标集中在 `Assets/Travel/TravelModel.cs`。

在 Unity 菜单选择 **行旅 → 验证地图原型**，可重复检查不同刷新率下的官道往返、地图切换和御剑计时。界面字库随游戏附带，授权文本位于 `Assets/StreamingAssets/NotoSansSC-LICENSE.txt`。
